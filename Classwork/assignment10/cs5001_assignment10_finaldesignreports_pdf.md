Project Abstract: 
EON-OpenSlicer is a centralized 3D printing lab management system designed to 
streamline the submission, tracking, and completion of print jobs. The 
platform improves workflow efficiency by organizing requests, managing 
printer resources, and providing clear communication between users and 
operators. We want EON-OpenSlicer to utilize the cloud which is superior to current 3d 
printing systems currently in place. This report combines revised and updated 
work from all Fall assignments.

User Stories and Design Diagrams (Assignment #4) 
   GitHub Link 4: https://github.com/Electrovian/Project-
EON-OpenSlicer/tree/Main/Classwork/assignment4 
Summary: 
The design diagrams show how the EON-OpenSlicer system handles print requests. 
Level 0 gives a simple overview of users interacting with the system. 
Level 1 breaks the system into main parts such as job submission, the job 
queue, and printer management. 
Level 2 shows more detailed steps like validating files, scheduling prints, and 
notifying users. 
Boxes represent system components, and arrows show the direction of data 
flow. The diagrams help us understand how information moves through the 
system and how each part works together.
