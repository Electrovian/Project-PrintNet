**Meeting Frequency & Timing:**We will meet twice weekly (Tuesday evenings and Friday afternoons) for 60–90 minutes, with additional meetings as needed. Collaboration tools include Microsoft Teams and GitHub.

**Project Focus:**Our capstone project is a 3D Printing Lab Management Platform inspired by 3D Print OS but tailored for UC’s 3D Print Farm. It addresses the current gap of having only an informational website by introducing a full workflow system for students, managers, and administrators.

**Core MVP Features:**- Student file submission with integrated slicer (based on open-source slicers)- UC email authentication and role-based access- Job queueing system with approval workflows- Manager dashboard for approving/rejecting and editing prints- Airtable workflow integration, with custom workflow option- Printer compatibility: MakerGear Series 2 through Bambu Lab printers- Toggleable cost visibility (Managers/Admins only)

**Expanded Features:**1. Real-time printer monitoring with webcams and status dashboard2. Automated maintenance: bed leveling, nozzle diagnostics, usage logging3. Filament & inventory tracking4. Usage analytics dashboard with exportable reports5. File management enhancements: versioning, mesh repair, estimates6. Notifications and alerts (student emails, manager error alerts)7. Mobile-friendly responsive interface8. Plugin/API support for OctoFarm, Repetier, and UC expansion9. Security: UC SSO integration, data encryption, role enforcement10. User quotas & print limits11. Multi-step approval workflows12. Failure & retry management13. Accessibility and internationalization14. Audit trail & logging of all actions15. Backup & disaster recovery plan16. Instructor/class integration dashboard17. Printer fleet health metrics (uptime, maintenance cycles)18. Future billing integration hooks19. AI mesh validation (experimental)

**Roles:**- Mitchell Koski (Lead Integration Engineer): Responsible for UC email authentication, Airtable/custom workflow, cloud deployment, printer integration, cost visibility toggle, and ensuring compatibility across printer models.- Muhanad Al-Khasawneh (Frontend Developer): Develops student-facing submission portal, in-browser slicer UI, self-help portal, and mobile interface.- Muneer Al-Khasawneh (Systems Engineer): Builds manager/admin dashboards, maintenance tools, fleet monitoring, and analytics modules.
