**Project Focus:**
Our capstone project is a 3D Printing Lab Management Platform inspired by 3D Print OS but tailored for UC's 3D Print Farm. It addresses the current gap of having only an informational website by introducing a full workflow system for students, managers, and administrators.

**Core MVP Features:**
- Student file submission with integrated slicer (based on open-source slicers)
- UC email authentication and role-based access
- Job queueing system with approval workflows
- Manager dashboard for approving/rejecting and editing prints
- Airtable workflow integration, with custom workflow option
- Printer compatibility: MakerGear Series 2 through Bambu Lab printers
- Toggleable cost visibility (managers/admins only)

**Expanded Features:**
1. Real-time printer monitoring with webcams and status dashboard
2. Automated maintenance: bed leveling, nozzle diagnostics, usage logging
3. Filament and inventory tracking
4. Usage analytics dashboard with exportable reports
5. File management enhancements: versioning, mesh repair, estimates
6. Notifications and alerts (student emails, manager error alerts)
7. Mobile-friendly responsive interface
8. Plugin/API support for OctoFarm, Repetier, and UC expansion
9. Security: UC SSO integration, data encryption, role enforcement
10. User quotas and print limits
11. Multi-step approval workflows
12. Failure and retry management
13. Accessibility and internationalization
14. Audit trail and logging of all actions
15. Backup and disaster recovery plan
16. Instructor/class integration dashboard
17. Printer fleet health metrics (uptime, maintenance cycles)
18. Future billing integration hooks
19. AI mesh validation (experimental)
