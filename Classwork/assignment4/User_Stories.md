# User_Stories.md — EON-OpenSlicer

**Project Title:** EON-OpenSlicer  
**Goal:** Connect multiple 3D printers to a single UI with integrated maintenance, Airtable sync, and built-in slicing (Slic3r).

## User Stories
- As a **general user**, I want to submit a 3D print job (STL/3MF) through a web portal so that I can get parts printed without visiting the lab in person.
- As **staff**, I want to view the print queue and run jobs on specific printers so that I can manage throughput and keep machines busy.
- As a **manager**, I want to approve/deny and prioritize submitted jobs so that lab policy is enforced and critical prints are completed first.
- As an **admin**, I want to maintain users/roles, printers, and maintenance policies so that the lab remains secure, available, and in good working order.
- As a **dev**, I want API/token-based access and webhooks so that I can integrate EON-OpenSlicer with other systems and automate workflows.
