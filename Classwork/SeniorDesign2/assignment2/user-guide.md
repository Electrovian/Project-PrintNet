# PrintNet User Guide

## Getting Started
PrintNet allows users to submit 3D models and print them without needing to configure printers manually.

## Uploading a Model
1. Log into PrintNet
2. Upload an STL or 3MF file
3. Select a printer (if applicable)
4. Submit the job

## Monitoring a Print
- View printer status in real time
- See queued and active jobs
- Receive completion updates

## Canceling a Job
- Select an active job
- Click cancel
- The printer will safely stop the print
