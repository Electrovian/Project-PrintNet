# PrintNet User Documentation

Welcome to the PrintNet user documentation.  
This guide explains how to install, use, and interact with the PrintNet system.

## 📘 Documentation Sections

- 👉 [User Guide](user-guide.md)  
  Step-by-step instructions for everyday users.

- 👉 [User Manual](user-manual.md)  
  Detailed explanations of system features and behavior.

- 👉 [FAQ](faq.md)  
  Answers to common questions and troubleshooting tips.

## Who is this for?
- Students submitting 3D print jobs
- Lab users interacting with PrintNet
- Administrators monitoring printers

PrintNet is designed to simplify 3D printing by handling slicing, job submission, and printer communication automatically.
