# PrintNet User Documentation

Welcome to **PrintNet**, a centralized 3D printing management system designed to streamline student submissions, slicing, printer queueing, and lab workflows.

PrintNet simplifies the entire 3D printing process by handling model intake, slicing, job management, and printer communication in one unified system.

## 🚀 Getting Started (Quick Overview)

At a high level, using PrintNet involves:
1. Installing dependencies (Python, libraries)
2. Launching the PrintNet application
3. Loading a 3D model (STL)
4. Slicing the model
5. Sending the job to a connected printer

Detailed steps are provided in the **User Guide**.

## 👥 Who Is This For?

- Students submitting 3D print jobs
- Lab users interacting with PrintNet
- Administrators and lab staff monitoring printers

PrintNet is designed to replace manual workflows (email requests, SD cards, separate slicers) with a single, reliable system.
