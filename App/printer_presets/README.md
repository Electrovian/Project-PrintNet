# Printer Presets

This folder is the app-local home for offline printer preset seed resources.

Current structure:

- `App/printer_presets/seed_resources/printers`
  Contains non-JSON printer assets plus `printers_data.py`.
- `App/printer_presets/seed_resources/profiles`
  Contains vendor asset files and generated vendor Python modules under:
  `App/printer_presets/seed_resources/profiles/python_vendors`
