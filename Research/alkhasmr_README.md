# Research Notes – Mo Al-Khasawneh (alkhasmr)

This folder contains my individual research contributions for the EON-OpenSlicer senior design project (CS 5001).

## Files

- `alkhasmr_user_personas_use_cases.md`  
  Defines the main types of users who typically interact with 3D print lab systems and outlines common use cases for EON-OpenSlicer.

- `alkhasmr_lab_workflow_mapping.md`  
  Describes a general 3D print lab workflow (submission → approval → printing → pickup) and identifies areas where centralized software can improve efficiency.

- `alkhasmr_hardware_integration.md`  
  Provides an overview of how EON-OpenSlicer may interact with printer hardware through tools like OctoPrint or similar controllers.

- `alkhasmr_ui_overview.md`  
  Summarizes planned UI/UX direction for EON-OpenSlicer, including simplicity for beginners and key screens such as submission, dashboard, and job tracking.

## Purpose

These documents help define:

- Who will use EON-OpenSlicer
- Typical workflows in 3D printing environments
- How hardware may connect to the software
- Early UI/UX direction

They will support future development and guide discussions with the lab about actual requirements.
