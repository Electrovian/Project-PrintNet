# UI/UX Design Principles for EON-OpenSlicer
Author: Mo Al-Khasawneh (alkhasmr)  
Course: CS 5001 – Senior Design

## 1. Overview
Since many students using the 3D print lab may be beginners, EON-OpenSlicer’s interface must prioritize simplicity and clarity.

These guidelines are based on common UI/UX principles used in educational and lab management systems.

## 2. Core UI Goals
- Simple submission workflow
- Clear status indicators
- Minimal required decision-making
- Consistent layout across pages

## 3. Key Design Principles

### 3.1 Simplicity
Avoid overwhelming new users with technical options.  
Provide presets and recommended defaults.

### 3.2 Clear Feedback
Users should always know:
- What stage their job is in
- Estimated time remaining
- Whether action is required

### 3.3 Accessibility
Use:
- Readable fonts
- High contrast
- Clear icons and labels

### 3.4 Mobile-Friendly
Many students check status from their phones, so a responsive layout is beneficial.

## 4. Planned UI Pages
- Login / access page
- Job submission form
- “My Jobs” status view
- Lab dashboard (TA/Manager)
- Printer detail pages
